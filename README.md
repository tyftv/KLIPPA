# KLIPPA
Hard/soft clipper VST3. Drive, Curve (hard to soft), Asymmetry, Ceiling, Mix, oversampling (Off/2x/4x/8x), live in/out scope and meters.
Output never exceeds the ceiling. Zero latency with oversampling off; otherwise the plugin reports its latency to the host.

Install (Windows / FL Studio): download the artifact from the Actions tab, copy `KLIPPA.vst3`
to `C:\Program Files\Common Files\VST3`, then rescan plugins in FL Studio.
