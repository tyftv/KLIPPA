# KLIPPA
Hard/soft clipper VST3. Drive, Curve (hard to soft), Ceiling, Mix, optional HQ (4x oversampling).
Output never exceeds the ceiling. Zero latency with HQ off; HQ reports its latency to the host.

Install (Windows / FL Studio): download the artifact from the Actions tab, copy `KLIPPA.vst3`
to `C:\Program Files\Common Files\VST3`, then rescan plugins in FL Studio.
